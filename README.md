# Bayside Pools — Fremont

Responsive marketing website for Bayside Pools in Fremont, California.

## What's included

- Mobile-friendly service pages and customer quote flow
- SEO metadata, LocalBusiness structured data, robots.txt, and sitemap.xml
- Four original, optimized pool photographs
- Phone and SMS contact actions using the published directory phone number
- Review rating link to PoolPad's Fremont directory listing

## Preview / deploy

This is a static site. The production version is published at https://baysidepools.raivyn.io/ after DNS verification. Open `index.html` locally or host the repository with GitHub Pages or another static host.
